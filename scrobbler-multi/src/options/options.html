Multi-Account Scrobbler

Scrobbles every SessionBox Spotify tab, including background tabs.

1. API credentials

Register one app at last.fm/api (and, for Libre.fm, at libre.fm). Leave the callback URL blank. These are shared by every account. ListenBrainz needs nothing here.

2. Default account — receives ALL profiles

Connect one scrobbling account here and every Spotify tab scrobbles to it. This is the setup for "many Spotify accounts → one Last.fm." A per-profile connection below overrides the default for that profile.

3. Per-profile overrides

Play a track in each SessionBox Spotify tab once — the account appears here. Only set a connection on a profile if it should go somewhere different from the default above.
