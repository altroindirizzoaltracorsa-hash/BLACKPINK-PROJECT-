Multi-Account Scrobbler

Each SessionBox Spotify tab scrobbles to its own accounts.

1. API credentials

Register one app at last.fm/api (and, for Libre.fm, at libre.fm). These are shared by every profile — only the per-account login differs. ListenBrainz needs nothing here.

2. Spotify profiles

Play a track in each SessionBox Spotify tab once — the account appears here. Then type that account's own Last.fm / Libre.fm login (or ListenBrainz token) into its row. Each profile connects independently, so different profiles go to different scrobbling accounts.
